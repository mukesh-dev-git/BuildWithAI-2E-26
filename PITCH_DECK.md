## 📌 1. The Problem Statement
- **The Voice Gap in Rural India:** 700M+ citizens in aspirational districts speak 22+ local dialects. Filing a grievance on traditional text portals requires literacy, English/Hindi fluency, and administrative navigation skills.
- **The Black-Box Governance Problem:** Bureaucracies allocate ₹3+ Lakh Crore annually in infrastructure funds (PMGSY, Jal Jeevan Mission, AMRUT) based on outdated annual reports, discretionary allocations, or political lobbying.
- **The Reactive Failure Loop:** Infrastructure is repaired only *after* catastrophic failure (collapsed bridges, contamination outbreaks, transformer explosions) rather than proactively predicted.

## 🧠 4. The Core Innovation: Explainable Priority Index (EPI)
Unlike opaque machine learning models that administrators cannot trust or audit, VikasDrishti AI uses an auditable, transparent priority scoring formula:

$$\text{EPI} = w_1(\text{Demand Density}) + w_2(\text{Vulnerability}) + w_3(\text{Infra Gap}) + w_4(\text{Budget Slack})$$

- **Demand Density ($w_1 = 0.30$):** Real-time citizen reports weighted by severity and community endorsements per 100k population.
- **Vulnerability Index ($w_2 = 0.25$):** BPL ratio $\times$ (1 - Literacy Rate).
- **Infrastructure Gap ($w_3 = 0.25$):** Multi-sector deficit (water, roads, health, power).
- **Budget Slack ($w_4 = 0.20$):** Unutilized capital expenditure from current allocations.

Every single priority score generated in the platform has a **1-click expandable mathematical audit trail**.
